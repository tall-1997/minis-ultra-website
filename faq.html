FAQ

先把会装错的事说清楚。

这是官方 OpenMinis 吗？

不是。这是 GPL-3.0 fork，启动器叫 Minis Ultra。官方产品与网站仍是 openminis.app。

能和官方 App 一起装吗？

能。包名不同：官方 com.openminis.app，本分支 com.openminis.linux。签名也不同，不能互相覆盖。

必须 root 吗？

不必。沙箱本身用 PRoot。主机 su 只在你要驱动 Magisk/KernelSU 时才需要；否则 Agent 仍可在客户机里跑 apt 与脚本。

沙箱 root 等于手机 root 吗？

不等于。PRoot 假装 uid 0。真主机权限走 android-su / su。

中转站模型为什么上下文是 256k？

接口往往只给 id。本分支用 models.dev 与 DataLearner 补参数；仍空的字段默认 256k 上下文、128k 输出、开启思考（最高 max）、文本模态。目录或你手改的值优先。

如何检查更新？

应用内关于页指向本 fork。滚动包标签是 android-latest。不要去官方商店找 Minis Ultra。

为什么 APK 很大、首次很慢？

内含 Ubuntu rootfs 与 aarch64 工具。第一次启动要解压客户机。

x86 模拟器能装吗？

发行包是 arm64-v8a。x86_64 模拟器通常不行。

源码在哪？

github.com/tall-1997/OpenMinis-Linux。上游 OpenMinis/OpenMinis。
