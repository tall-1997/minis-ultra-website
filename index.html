01 — 定位

端侧私人 Agent，沙箱即电脑。

把 Claude、GPT、Gemini 接到本机 Ubuntu：浏览器自动化、技能与记忆、多智能体调度。检查更新指向 fork tall-1997/OpenMinis-Linux。

Ubuntu 24.04 客户机

Canonical ubuntu-base arm64，跑在 PRoot 里。glibc、apt、bash。不是 KVM，也不依赖内核 user namespace。

主机 su 直通

优先 Magisk / KernelSU；没有 su 时经 Shizuku 重试。设置里 Host su 与 Shizuku 并列。

与官方并排

独立包名、启动器名、抽象套接字和调试端口。官方 Minis 不用卸，Ultra 可以一起装。

02 — 能力

Agent 会用工具，也会调度团队。

模型参数补全

models.dev 归一化匹配，DataLearner 补洞，中转站脏名按字重合。缺参默认 256k / 128k / 思考 max / 文本。

多智能体

主会话当协调者。并发 1–8、自定义协作角色、计划讨论。深链 minis://settings/multi-agent。

SecurityGate

ASK 默认、argv 风险、sha256 审计链。对话内审批卡；本会话全部允许会在会话结束复位。

技能与人格

启动扫描 minis-global/skills，默认全开。人格无字数上限。工作区规则作为 Markdown 文件库。

浏览器自动化

browser_use 跟系统 WebView。沙箱可 minis-open 调起主机浏览器。

定时与插件

cronjob、插件市场（MCP 预设 + OpenAPI，SSRF 校验，密钥不进模型上下文）。

POSIX 存储

有全部文件访问时挂 /sdcard。SAF 目录绑在 /var/minis/mounts/。

工具限额

Shell 超时、file_read 字符/行数、子代理轮次。点 − / 数字 / + 中间可输入，确定时夹紧。
