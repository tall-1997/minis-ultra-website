沙箱

客户机里假装 uid 0，主机 root 另走 su。

PRoot 会在 Ubuntu 里假装 root，那不是手机 root。真主机权限只来自 Magisk / KernelSU 的卸载通道，或 Shizuku 回落。

客户机规格

libc：glibc aarch64-linux-gnu
shell：GNU bash，/bin/sh 是 dash
软件包：apt（yum/dnf 只是包装）
软件源：ports.ubuntu.com
init：无 systemd

工具链

minis-dev-setup 安装 bash、gcc、python3、git、ffmpeg、openjdk-21、gradle、golang-go。minis-android-sdk-setup 配 aarch64 aapt2 与平台。

不要在客户机里用 sdkmanager 装 Google 的 linux x86_64 build-tools / cmake / ndk。那会把 aapt2 覆盖成无法执行的 ELF。

主机通道

沙箱当服务器。

minis-toast 备份完成
minis-clipboard get
minis-open --system https://example.com
minis-firewall set wifi-only
minis-firewall cut
minis-notify post --title 完成 --body ok
minis-on-event register battery_low /var/minis/hooks/pause.sh
android-su status
# status files
cat /run/minis-host-status.json
cat /run/android-events.jsonl

共享存储

SAF 绑定 /var/minis/mounts/<name>/。有全部文件访问时还有 /sdcard 与 /storage/emulated/0。

Host su

深链 minis://settings/host-su。su -c id 与 android-su status 用于确认。

多智能体

主会话拆解分派。子代理看不到主会话，prompt 必须自包含，禁止再开子代理。
